# ttfchart

Generate a PDF glyph chart for a TrueType/OpenType font — a "Font Information"
title page followed by a grid of every glyph the font's cmap exposes, grouped
by Unicode block. Color glyph formats (COLR/CPAL, OT-SVG, CBDT/CBLC, sbix) are
detected and rasterized so emoji-style fonts (e.g. Noto Color Emoji) render in
color instead of as blank or outline glyphs.

This is useful for font QA, spot-checking Unicode coverage, or just getting a
printable reference sheet for a typeface.

> **Note:** Both this README and `ttfchart.py` were generated by Claude
> (Anthropic).

## What it produces

- **Page 1 — Font Information:** family/style name, version, designer,
  copyright, license description, whether the font contains color glyphs, and
  a pangram text sample rendered in the font itself.
- **Following pages — Glyph grid:** every chartable codepoint in the font's
  `cmap`, grouped under a heading for its Unicode block, 14 glyphs per row,
  each cell labeled with its codepoint (`U+XXXX` shown as hex).

Control/format/surrogate codepoints (Unicode categories `Cc`, `Cf`, `Cs`) are
excluded from the chart.

## Installation

Requires Python 3.10+.

```bash
# Run directly with uv (no separate install step)
uv run python ttfchart.py path/to/font.ttf

# Or install the dependencies yourself
pip install fonttools pillow reportlab
python ttfchart.py path/to/font.ttf
```

### Optional: Inkscape (for OT-SVG color fonts)

Fonts that use the **OT-SVG** color format (an `SVG ` table) are rasterized by
shelling out to [Inkscape](https://inkscape.org/)'s batch mode. If `inkscape`
isn't found on `PATH`, those glyphs are skipped with a warning — everything
else in the chart still renders normally.

```bash
# Debian/Ubuntu
sudo apt install inkscape

# macOS
brew install inkscape
```

Color fonts using **COLR/CPAL**, **CBDT/CBLC**, or **sbix** do not need
Inkscape; those are rasterized directly via Pillow/FreeType.

## Usage

```bash
ttfchart.py <font.ttf|font.otf> [-o output.pdf]
```

| Argument | Description |
|---|---|
| `font` | Path to a `.ttf` or `.otf` font file (required). |
| `-o`, `--output` | Output PDF path. Defaults to `<font>.pdf` in the current directory. |

### Examples

```bash
# Basic usage, writes ./NotoSans.pdf
uv run python ttfchart.py NotoSans-Regular.ttf

# Explicit output path
uv run python ttfchart.py NotoColorEmoji.ttf -o emoji-chart.pdf
```

## How it works

- Font metadata and the character map (`cmap`) are read with
  [fontTools](https://github.com/fonttools/fonttools).
- Codepoints are grouped by Unicode block using `fontTools.unicodedata`.
- Color glyph tables (`SVG `, `COLR`, `CBLC`/`sbix`) are inspected to decide,
  per glyph, whether it should be drawn as a raster image or as vector text.
- Vector (non-color) glyphs are drawn by embedding the font directly into the
  PDF via [ReportLab](https://www.reportlab.com/) (`pdfbase.ttfonts`), so the
  chart reflects the font's actual outlines rather than a system fallback.
- Color glyphs are rasterized with [Pillow](https://python-pillow.org/)
  (COLR/CBDT/sbix, via FreeType's embedded-color text rendering) or with
  Inkscape's shell mode (OT-SVG).

## Known limitations

- Large fonts (thousands of glyphs, e.g. CJK or emoji sets) produce
  multi-hundred-page PDFs and can take a while to render.
- OT-SVG color glyphs are silently skipped if Inkscape isn't installed; the
  rest of the chart is unaffected.
- Font metadata fields (version, designer, copyright, license) are only as
  complete as what the font itself embeds in its `name` table — missing
  fields are simply omitted from the info page.
- Only the font's `cmap`-mapped codepoints are charted; glyphs with no
  Unicode mapping (e.g. ligature-only or stylistic-alternate glyphs reachable
  only via OpenType features) are not shown.

## Dependencies

| Package | Purpose |
|---|---|
| [fontTools](https://pypi.org/project/fonttools/) | Font parsing, cmap/table introspection, Unicode block lookup |
| [Pillow](https://pypi.org/project/pillow/) | Rasterizing COLR/CBDT/sbix color glyphs |
| [ReportLab](https://pypi.org/project/reportlab/) | PDF generation and embedded vector font rendering |
| [Inkscape](https://inkscape.org/) *(optional, external)* | Rasterizing OT-SVG color glyphs |
